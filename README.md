This project focuses on predicting the likelihood of heart disease using machine learning techniques. By analyzing patient health data, the model helps in early detection and supports better medical decision-making.

🎯 Objective


To build a predictive model for heart disease detection


To analyze key health factors affecting heart conditions


To improve accuracy using data preprocessing and feature engineering



📊 Dataset
The dataset includes various medical attributes such as:


Age


Sex


Chest Pain Type


Blood Pressure


Cholesterol Level


Maximum Heart Rate


Fasting Blood Sugar


ECG Results



⚙️ Technologies Used


Python 🐍


Pandas & NumPy


Matplotlib & Seaborn


Scikit-learn



🔍 Project Workflow


Data Collection


Data Cleaning & Preprocessing


Exploratory Data Analysis (EDA)


Feature Selection


Model Building (e.g., Logistic Regression, Decision Tree)


Model Evaluation



📈 Results
The model provides predictions on whether a patient is at risk of heart disease, achieving reliable accuracy through proper training and validation techniques.
